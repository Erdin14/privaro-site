Vragen

Kan iemand anders mijn foto’s zien?

Nee. Ze worden op je iPhone versleuteld met een sleutel die daar blijft. Er is geen Privaro-account en geen server met je foto’s, dus er valt voor niemand iets te zien, ook niet voor ons.

Wat als ik mijn code vergeet?

Bij het instellen van Privaro krijg je een herstelsleutel. Bewaar die goed: daarmee stel je een nieuwe code in. Zonder code of herstelsleutel kan de kluis niet open, ook niet door ons.

Wat gebeurt er als ik mijn telefoon kwijtraak?

Had je de versleutelde iCloud-back-up (Pro) aan, dan zet je de kluis met je herstelsleutel terug op je nieuwe iPhone. Terugzetten is gratis. Zonder back-up blijven de foto’s op de oude telefoon op slot.

Is er een limiet voor de grootte van video’s?

Niet per bestand. Elke grootte werkt zolang je iPhone ruimte heeft. De gratis versie bewaart tot 2,5 GB in totaal, Pro heeft geen limiet.

Heb je een internetverbinding nodig?

Nee. Je kluis werkt volledig offline, en je foto’s gaan nooit online tenzij je de iCloud-back-up aanzet.

Is Pro een abonnement?

Nee. Pro is een eenmalige betaling van € 11,99. Er wordt niets verlengd en er valt niets op te zeggen.
