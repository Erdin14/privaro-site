Privaro

Ein Tresor, den nur du öffnen kannst.

Privaro ist ein Tresor für die Fotos und Videos auf deinem iPhone. Was du hineinlegst, wird direkt auf dem Gerät verschlüsselt und öffnet sich nur mit Face ID oder dem eigenen Code von Privaro. Kein Konto, kein Upload.

Kostenlos laden. Benötigt iOS 17.6 oder neuer. Pro ist optional: einmalig 9,99 €, kein Abo.

Mit dem iPhone scannen

Auf deinem iPhone verschlüsselt. Mit einem Schlüssel, der darauf bleibt.

AES-256
Jedes Foto und Video im Tresor wird direkt auf dem Gerät mit AES-256 verschlüsselt.
Kein Konto
Keine Anmeldung und kein Privaro-Server, der deine Fotos speichert.
Face ID oder Code
Der Tresor öffnet sich nur mit Face ID oder dem eigenen Code von Privaro.
Funktioniert offline
Deine Fotos gehen nur online, wenn du das verschlüsselte iCloud-Backup aktivierst.
Sicherheitsübersicht lesen

Was ist, wenn jemand anderes hineinwill?

In Pro enthalten

  • Schein-Tresor

    Lege einen zweiten Code fest, der einen separaten Tresor mit harmlosen Fotos öffnet. Wirst du je gedrängt, Privaro zu entsperren, gibst du diesen ein, und dein echter Tresor bleibt unsichtbar.

  • Notlöschung

    Lege einen Code fest, der den ganzen Tresor samt Köder löscht, sobald er eingegeben wird. Er ist für den schlimmsten Fall gedacht und lässt sich nicht rückgängig machen.

  • Einbruchsaufnahme

    Gibt jemand einen falschen Code ein, kann Privaro lautlos ein Foto mit der Frontkamera aufnehmen und den Versuch mit Zeitstempel protokollieren, damit du weißt, ob jemand versucht hat, in deinen Tresor zu gelangen.

9,99 € Einmal bezahlen, kein Abo.
