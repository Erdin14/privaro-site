Fragen

Kann jemand anderes meine Fotos sehen?

Nein. Sie werden auf deinem iPhone mit einem Schlüssel verschlüsselt, der dort bleibt. Es gibt kein Privaro-Konto und keinen Server mit deinen Fotos, also gibt es für niemanden etwas zu sehen, auch nicht für uns.

Was ist, wenn ich meinen Code vergesse?

Bei der Einrichtung bekommst du einen Wiederherstellungsschlüssel. Bewahre ihn sicher auf: Damit kannst du einen neuen Code festlegen. Ohne Code oder Schlüssel lässt sich der Tresor nicht öffnen, auch nicht von uns.

Was passiert, wenn ich mein iPhone verliere?

Hast du das verschlüsselte iCloud-Backup (Pro) aktiviert, stellst du den Tresor mit deinem Wiederherstellungsschlüssel auf dem neuen iPhone wieder her. Das Wiederherstellen ist kostenlos. Ohne Backup bleiben die Fotos auf dem alten Gerät verschlossen.

Gibt es eine Größenbeschränkung für Videos?

Nicht pro Datei. Jede Größe geht, solange dein iPhone Platz hat. Die kostenlose Version fasst insgesamt bis zu 2,5 GB, Pro hat keine Grenze.

Braucht es eine Internetverbindung?

Nein. Dein Tresor funktioniert komplett offline, und deine Fotos gehen nie ins Internet, außer du aktivierst das iCloud-Backup.

Ist Pro ein Abo?

Nein. Pro ist eine einmalige Zahlung von 5,99 €. Nichts verlängert sich, nichts muss gekündigt werden.
