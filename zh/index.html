Privaro

只有你能打开的保险库。

Privaro 是 iPhone 上存放照片和视频的保险库。放进去的内容会直接在手机上加密，只能用面容 ID 或 Privaro 自己的密码打开。无需账户，也不会上传任何内容。

免费下载。需要 iOS 17.6 或更高版本。 Pro 为可选项：一次性支付 ¥148，无需续订。

无需账户

如果别人想打开呢？

Pro 包含

  • 诱饵保险库

    设置第二个密码，用来打开一个只有普通照片的独立保险库。万一有人逼你解锁 Privaro，就输入这个密码，真正的保险库不会露面。

  • 胁迫抹除

    设置一个密码，一旦输入就会抹除整个保险库，包括诱饵。这是为最坏的情况准备的，无法撤销。

  • 闯入抓拍

    如果有人输入错误密码，Privaro 可以用前置摄像头悄悄拍照，并记录带时间戳的尝试，让你知道是否有人试图进入你的保险库。
