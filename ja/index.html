Privaro

あなたにしか開けない保管庫。

Privaro は iPhone のための保管庫です。入れたものは iPhone 本体で暗号化され、Face ID か Privaro 専用のパスコードでしか開けません。アカウントは不要で、何もアップロードされません。

無料でダウンロード。iOS 17.6 以降が必要です。 Pro は任意です。￥800 の買い切りで、更新はありません。

iPhone上で暗号化。 鍵は、iPhone の中だけに。

AES-256
保管庫の写真とビデオはすべて、デバイス上で AES-256 により暗号化されます。
アカウント不要
登録は不要。写真を保管する Privaro のサーバーもありません。
Face ID またはパスコード
保管庫は Face ID か Privaro 専用のパスコードでしか開きません。
オフラインで動作
写真がオンラインに送られるのは、暗号化 iCloud バックアップをオンにしたときだけです。
