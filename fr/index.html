Privaro

Un coffre-fort que vous seul pouvez ouvrir.

Privaro est un coffre-fort pour votre iPhone. Ce que vous y placez est chiffré sur le téléphone lui-même et ne s’ouvre qu’avec Face ID ou le code de Privaro. Pas de compte, et rien n’est envoyé.

Téléchargement gratuit. Nécessite iOS 17.6 ou ultérieur. Pro est facultatif : un seul paiement de 5,99 €, rien à renouveler.

Chiffré sur votre iPhone. Avec une clé qui y reste.

AES-256
Chaque photo et vidéo de votre coffre est chiffrée en AES-256, directement sur l’appareil.
Sans compte
Aucune inscription, et aucun serveur Privaro qui stocke vos photos.
Face ID ou code
Le coffre ne s’ouvre qu’avec Face ID ou le code de Privaro.
Fonctionne hors ligne
Vos photos ne passent en ligne que si vous activez la sauvegarde iCloud chiffrée.
