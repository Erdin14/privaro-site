Privaro

Un coffre-fort que vous seul pouvez ouvrir.

Privaro est un coffre-fort pour les photos et les vidéos de votre iPhone. Ce que vous y placez est chiffré sur le téléphone lui-même et ne s’ouvre qu’avec Face ID ou le code de Privaro. Pas de compte, et rien n’est envoyé.

Téléchargement gratuit. Nécessite iOS 17.6 ou ultérieur. Pro est facultatif : un seul paiement de 9,99 €, rien à renouveler.

Scannez avec votre iPhone

Chiffré sur votre iPhone. Avec une clé qui y reste.

AES-256
Chaque photo et vidéo de votre coffre est chiffrée en AES-256, directement sur l’appareil.
Sans compte
Aucune inscription, et aucun serveur Privaro qui stocke vos photos.
Face ID ou code
Le coffre ne s’ouvre qu’avec Face ID ou le code de Privaro.
Fonctionne hors ligne
Vos photos ne passent en ligne que si vous activez la sauvegarde iCloud chiffrée.

Et si quelqu’un d’autre veut entrer ?

Inclus dans Pro

  • Coffre-fort leurre

    Définissez un second code qui ouvre un coffre-fort distinct, rempli de photos anodines. Si l’on vous force un jour à déverrouiller Privaro, saisissez celui-là : votre vrai coffre-fort reste invisible.

  • Effacement sous contrainte

    Définissez un code qui efface tout le coffre-fort, leurre compris, dès qu’il est saisi. C’est prévu pour le pire des cas, et c’est irréversible.

  • Capture d’intrusion

    Si quelqu’un saisit un mauvais code, Privaro peut prendre discrètement une photo avec la caméra frontale et consigner la tentative avec un horodatage, pour que vous sachiez si quelqu’un a essayé d’accéder à votre coffre-fort.
