Privaro

只有你能打開的保險庫。

Privaro 是 iPhone 上的保險庫。放進去的內容會在手機本身加密，只有 Face ID 或 Privaro 自己的密碼才能打開。不需要帳號，也不會上傳任何內容。

安全性

在你的 iPhone 上加密。 金鑰始終留在手機上。

  • AES-256

    保險庫中的每張照片和每段影片都直接在裝置上以 AES-256 加密。

  • 不需要帳號

    無須註冊，也沒有 Privaro 伺服器保存你的照片。

  • Face ID 或密碼

    保險庫只能用 Face ID 或 Privaro 自己的密碼打開。

  • 離線可用

    只有開啟加密 iCloud 備份時，你的照片才會上網。
